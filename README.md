# \# Portfolio

# 

# Подборка моих проектов на C++.

# 

# 

# \- \*\*\[Web server](./web-server)\*\* — многопользовательский HTTP/игровой сервер на C++17 с асинхронным I/O на Boost.Asio/Beast, PostgreSQL, JSON-логированием, тестами, Docker и Conan.

# 

# \- \*\*\[Order Book / Биржевой стакан](./Stakan)\*\* — командный C++20-проект: многопоточный сервис обработки торговых данных с TCP-клиентом, клиентской библиотекой, консольным клиентом, Boost и Catch2. Мой вклад: интерфейс клиентской библиотеки, рефакторинг `bid\_ask\_book`, доработка потокобезопасности, `GetTopSnapshot`, тесты и отображение `MDUpdate`.

# 

# \- \*\*\[Spreadsheet](./spreadsheet)\*\* — мини-Excel на C++17: формулы, зависимости между ячейками, кэширование вычислений, обработка ошибок и защита от циклических зависимостей; парсинг формул через ANTLR.

# 

# \- \*\*\[Transport catalogue](./transport-catalogue)\*\* — транспортный справочник на C++: JSON API, маршрутизация на графе, построение кратчайшего маршрута и генерация SVG-карты.
